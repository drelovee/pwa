# SkillCrew Remote PWA

Это новая основа приложения без локальной SQLite и без `better-sqlite3`. Данные хранятся в удалённой PostgreSQL базе через `DATABASE_URL`.

## Что уже есть

- PWA manifest, мобильная и desktop веб-версия.
- Регистрация/вход через httpOnly cookie.
- Две роли: `executor` и `customer`.
- Профиль: имя, @username, описание, роль, суммы-заглушки.
- Категории и подкатегории.
- Витрина: поиск по публикациям и профилям.
- Заказчик создаёт заказ, исполнитель создаёт объявление.
- Отклик создаёт чат.
- В чате есть системные сообщения и кнопка подтверждения заказа.
- После подтверждения создаётся активный заказ.
- Команды: создание, заявки, предложение проекта команде через админа.
- Админка: обзор пользователей, категорий, публикаций, чатов, команд; создание категорий.

## Что пока заглушки

- Настоящие push-уведомления.
- Платежи и вывод средств.
- Загрузка файлов/аватаров на S3.
- Полная модерация и жалобы.

## Быстрый запуск

1. Установить Node.js 22 LTS.
2. Создать удалённую PostgreSQL базу.
3. Скопировать `.env.example` в `.env`.
4. Вставить `DATABASE_URL`.

```bash
npm install
npx prisma generate
npx prisma db push
npm run db:seed
npm run dev
```

Открыть:

```text
http://localhost:3000
```

Админ после seed:

```text
admin@skillcrew.local
12345678
```

## Важно про удалённую БД и РФ

Для разработки можно использовать бесплатную Postgres-БД, например Neon/Render. Для стабильной работы без VPN в России лучше итогово перенести БД и сайт на российский VPS с PostgreSQL, Nginx и HTTPS.

## Как сделать доступ с телефона локально

1. ПК и телефон должны быть в одной Wi-Fi сети.
2. Запустить:

```bash
npm run dev
```

3. Найти IPv4 ПК:

```bash
ipconfig
```

4. Открыть на телефоне:

```text
http://IP_КОМПЬЮТЕРА:3000
```

## Деплой на VPS

На сервере:

```bash
npm install
npx prisma generate
npx prisma db push
npm run build
npm run start
```

Нужны переменные:

```env
DATABASE_URL="postgresql://..."
JWT_SECRET="long_random_secret"
NEXT_PUBLIC_APP_URL="https://your-domain.ru"
```
